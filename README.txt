케이브덕 가이드 이미지 뷰어
==========================

구성
- index.html
- 1.png ~ 10.png

사용법
- PC: 좌/우 화살표 버튼 또는 키보드 ← →
- 모바일: 좌우 스와이프
- 하단 점을 눌러 원하는 장으로 이동
- 우측 상단 버튼으로 전체화면 전환
- URL 끝에 #5 처럼 붙이면 5번 장을 바로 열 수 있음

GitHub Pages에 올리는 가장 간단한 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 파일(index.html, 1.png~10.png)을 저장소 최상위에 전부 업로드합니다.
3. 저장소 Settings > Pages로 이동합니다.
4. Build and deployment의 Source를 "Deploy from a branch"로 선택합니다.
5. Branch를 main / (root)로 선택하고 Save 합니다.
6. 잠시 뒤 Pages 화면에 공개 주소가 표시됩니다.

주의
- 이미지 파일명을 바꾸면 index.html 안의 설정도 바꿔야 합니다.
- 현재는 1.png부터 10.png까지 총 10장을 기준으로 만들어져 있습니다.
